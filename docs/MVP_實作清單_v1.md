# MVP 實作清單 v1（個人財務管理 App）

- **版本**：v1
- **更新日期**：2026-04-22
- **適用情境**：第一批使用者只有自己、雙平台（iOS + Android）同時、收據 OCR 為 MVP 必需

---

## 0. 目標與驗收基準

### 北極星目標
- 每週活躍記帳天數（WAAD）≥ 5 天。

### MVP 驗收指標（8 週）
1. 新增一筆支出平均耗時 ≤ 30 秒。
2. OCR 流程從拍照到儲存完成平均 ≤ 10 秒（在識別成功情境）。
3. D7 留存（自用等價指標：7 天內至少記帳 5 天）達成。
4. 每週回顧通知點擊率 ≥ 60%（自用可先以「有無點開」人工記錄）。

## 2. 資料模型與核心 API（P0）

### 2.1 資料表
- [ ] `profiles`：基本資料、偏好設定。
- [ ] `transactions`：
  - id, user_id, type(income/expense), amount, currency,
  - date, category_id, merchant, payment_method,
  - note, receipt_url, created_at。
- [ ] `categories`：預設 12 類 + 自訂類別。
- [ ] `budgets`：月總預算、分類預算、提醒閾值。
- [ ] `goals`：目標金額、目標日期、目前進度。
- [ ] `subscriptions`：固定扣款項目（MVP 可先手動維護）。

### 2.2 API / Service 層
- [ ] 交易 CRUD。
- [ ] 預算扣減與剩餘計算。
- [ ] 目標進度更新（儲蓄分類時觸發）。
- [ ] 首頁摘要聚合查詢。

**DoD**
- 任一交易新增後，首頁摘要與預算數據在 2 秒內更新。

## 4. 收據 OCR（P0，MVP 必做）

### 4.1 拍照與上傳
- [ ] 相機拍照/相簿選取。
- [ ] 上傳至 Supabase Storage。

### 4.2 OCR 解析
- [ ] 串接 Google Vision API。
- [ ] 抽取欄位：金額、日期、商戶。
- [ ] 低信心欄位標記（需人工確認）。

### 4.3 確認與入帳
- [ ] OCR 預填記帳表單。
- [ ] 使用者確認後才可儲存。
- [ ] 失敗 fallback：保留圖片 + 手動輸入。

**DoD**
- 80% 常見收據可正確抽出至少 2 個核心欄位。
- 不存在「未確認直接入帳」路徑。

## 6. 預算與提醒（P0）

### 6.1 預算
- [ ] 月總預算設定。
- [ ] 分類預算設定（至少餐飲/交通/購物）。

### 6.2 提醒規則
- [ ] 70%：App 內提示。
- [ ] 90%：推送通知。
- [ ] 超支：推送 + 首頁警示卡。
- [ ] 月底前 3 天：日均可用額提示。

### 6.3 通知降噪
- [ ] 同分類 24 小時內最多推送 1 次。
- [ ] 單日最多推送 2 次。

**DoD**
- 任一分類跨越閾值後，提醒在 5 分鐘內觸發。

## 13. 8 週排程建議

- **W1-W2**：專案初始化、資料模型、登入、記帳基本流程。
- **W3**：首頁摘要卡 + 預算引擎。
- **W4**：OCR 串接與確認流程。
- **W5**：通知（預算提醒 + 每週回顧）。
- **W6**：分析頁第一層 + 目標基本功能。
- **W7**：穩定性、效能與 UX 微調。
- **W8**：自用壓測（連續 14 天）與 MVP 回顧。

## 15. 發版門檻（Go/No-Go）

符合以下條件才進入對外測試：
1. 連續 7 天每天可完成記帳。
2. OCR 三路徑（成功/低信心/失敗）皆可用。
3. 預算提醒正確率 100%（測試資料集）。
4. 無 P0 等級 crash。
