AI 識別單據

申請只需 2 分鐘，完全免費，有免費使用額度，不需要信用卡。
  1. 打開 Google AI Studio
    點下方按鈕，或在瀏覽器輸入 aistudio.google.com
  2. 登入 Google 帳號
    用平時用的 Gmail 帳號登入即可。
  3. 點「Get API key」
    在頁面左側邊欄或首頁找到「Get API key」按鈕。
  4. 建立新 Key
    點「Create API key」，選擇任意 Google Cloud 專案（或讓系統自動建立），再點「Create」。
  5. 複製 Key
    畫面會顯示一串以「AIza」開頭的金鑰，點複製圖示。
  6. 貼到上方輸入欄
    回到這個頁面，把剛才複製的 Key 貼到「Gemini Key」欄位，按「儲存」。
